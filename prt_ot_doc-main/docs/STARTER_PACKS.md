# STARTER_PACKS

Versioned packs находятся в `seed/tenant_starter_packs/v1/`:
- `default.json` — production/pilot starter.
- `demo.json` — demo-only starter.

Структура:
- `reference_data`
- `package_presets`
- `report_presets`
- `enabled_for`

Packs import/export friendly (JSON), можно включать по типу tenant/plan.
