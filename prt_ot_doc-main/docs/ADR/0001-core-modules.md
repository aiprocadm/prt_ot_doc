# ADR 0001: Core + Modules

## Статус
Принято

## Контекст
Платформа закрывает множество доменов (документы, обучение, СИЗ, инциденты) и должна масштабироваться под разные компании с различными наборами функций. Нужна единая база данных и сервисы, но без монолитной связи всех функций для каждого клиента.

## Решение
Принята архитектура **Core + Modules**:
- **Core** включает tenant‑контуры, компании, пользователей, документы, шаблоны, аудит и outbox.
- **Modules** (обучение, СИЗ, медосмотры, инциденты, риск, проверки, отчёты) разворачиваются поверх Core и включаются через фича‑флаги и тарифы.

## Последствия
- Упрощается масштабирование и монетизация за счёт включаемых модулей.
- Требуется согласованная схема миграций и единые интерфейсы взаимодействия модулей с Core.
- Спецификация и отчёты соответствия фиксируются отдельно для Core и модулей.
