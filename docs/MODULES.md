# Modules

- `branding` — effective organization profile, inheritance and preview.
- `headers` — persisted layout presets + DOCX header/footer injection.

- `replace` — placeholder replacement.
- `pdf` — conversion and file handling.
- `pipelines` — orchestration between stages.
- `workflow`, `approval`, `sign`, `edo` — downstream release flow.
