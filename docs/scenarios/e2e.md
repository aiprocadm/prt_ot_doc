# Сквозные сценарии (E2E)

Документ фиксирует ключевые сценарии из ТЗ, их статус и узкие места.

## 1) Выход на объект
**Цепочка:**
1. Создание объекта/площадки.
2. Назначение сотрудников.
3. Проверка готовности: обучение, СИЗ, риски.
4. Генерация пакета документов.
5. Появление задач/обязательств.
6. Отправка событий (outbox → webhook).

**Статус:** ✅ OK

**Проверки:**
- Создание объекта/площадки → `POST /sites`.
- Назначение сотрудников → `POST /persons`.
- Обучение/СИЗ/риски → `POST /training/plans`, `POST /ppe/assignments`, `POST /risk/assess`.
- Генерация пакета → `POST /packs/run` с дальнейшим статусом `GET /documents/tasks/{id}`.
- Обязательства → `GET /tasks`.
- События → `GET /admin/outbox`.

## 2) Обучение и обязательства
**Цепочка:**
1. Назначение обучения сотруднику.
2. Автосоздание задачи с дедлайном.
3. Напоминание (outbox).
4. Закрытие задачи после завершения обучения.
5. Обновление статуса сотрудника.

**Статус:** ✅ OK

**Проверки:**
- Назначение обучения → `POST /training/plans`.
- Автосоздание задачи → `GET /tasks?type=training_plan`.
- Напоминания → outbox события `TaskDueSoon` / `TaskOverdue`.
- Завершение обучения → `POST /training/sessions`.

## 3) Риск → мероприятие → задача
**Цепочка:**
1. Оценка риска.
2. Формирование плана мероприятий.
3. Автосоздание задач.
4. Отображение задач в общем реестре.
5. Закрытие мероприятия → пересчёт риска (если предусмотрено ТЗ).

**Статус:** ✅ OK

**Проверки:**
- Оценка риска → `POST /risk/assess`.
- План мероприятий и задачи → `GET /risk/action-plans`, `GET /tasks?type=risk_action`.
- Реестр задач → `GET /tasks` + фильтры.

## 4) Управленческий дашборд
**Цепочка:**
1. Запрос агрегатов.
2. Drill-down в реестры.

**Статус:** ✅ OK

**Проверки:**
- Сводка → `GET /dashboard/summary`.
- Переходы → `/tasks?overdue=true`, `/tasks?priority=critical`, `/incidents`, `/training`.

## Известные ограничения
- WS канал для мгновенных уведомлений пока заглушен (`/ws/v1/events` возвращает 501).
- Drill-down с фильтрами реализован для задач; для остальных реестров доступен переход без фильтров.
