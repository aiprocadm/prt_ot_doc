# Document core

## Pipeline
1. Template selection/versioning.
2. Branding resolution (tenant -> company -> site).
3. Layout preset rendering.
4. Header/footer injection into DOCX.
5. Replace and contextual data fill.
6. PDF conversion.
7. Approval/sign/EDO/archive.

## Reliability additions
- Header engine now emits explicit document relationships and content-type overrides for generated header/footer parts.
- Supports first/odd/even headers and footers.
- Tracks reproducibility metadata through branding preview responses.
