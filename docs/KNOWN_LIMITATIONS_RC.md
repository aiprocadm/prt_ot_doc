# KNOWN LIMITATIONS (RC)

## Внешние зависимости
- Полноценная проверка интеграций с внешними системами (ЭДО/подписи/внешние конвертеры) требует отдельного интеграционного стенда.

## Backend
- Полный end-to-end прогон всех доменных сценариев в рамках одного прохода не выполнен; закрыт только критичный регрессионный срез.

## CI / окружение
- В логах тестов сохраняются предупреждения сторонних библиотек (`pydantic`/`jose`), не влияющие на статус выполнения.

## Frontend / e2e
- В этом проходе не выполнялся визуальный e2e smoke через браузерный контейнер; требуется отдельный demo-smoke прогон UI-маршрутов.
