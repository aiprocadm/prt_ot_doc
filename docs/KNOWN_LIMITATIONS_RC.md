# KNOWN LIMITATIONS (RC)

## Backend / migrations
- Полный миграционный smoke в SQLite невозможен для части схемы из-за использования JSONB в initial migration; применяется fallback-сценарий smoke.

## CI / качество кода
- `make ci-local` падает на lint-этапе из-за крупного исторического хвоста `ruff`-нарушений в нескольких директориях.

## Внешние интеграции
- Полный production-grade прогон внешних интеграций (включая контуры, требующие внешнего стенда) не подтвержден в этом локальном RC-проходе; требуется отдельный стендовый verification.

## Frontend
- Production build проходит, но есть предупреждение о крупных чанках; требуется дальнейшая оптимизация bundle-size после релиз-кандидатной стабилизации.
